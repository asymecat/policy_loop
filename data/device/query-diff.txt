## Result

  host  expected  sha256 9076f29327457e5a21b1b24c88d325d46f127b66d0fa2f98295ddc14172f9b66
  device actual   sha256 9076f29327457e5a21b1b24c88d325d46f127b66d0fa2f98295ddc14172f9b66

  27912 lines / 2984884 bytes on both sides. Byte identical.

The digest covers every field the query path emits -- allowed, granted[],
ioctl_allowed, ioctl_reason, neverallow -- so this is one comparison over all
five, not five separate claims. A byte-identical digest on a 2.98 MB body is a
stronger statement than a per-field counter would be.

## Cost

  device  71.25 s real for 27912 queries (2.55 ms/query, incl. 297 ms index load)
  host    40.85 s for the same set               (1.46 ms/query)

The device runs on an RK3568 (4x Cortex-A55) against a desktop x86 -- 1.7x the
per-query cost on that hardware is the expected order, not a regression. What
matters for the tool's purpose is that the query path needs no host PC at all.

## Reproduce

  # host
  python3 /tmp/gen_queries.py            # -> /tmp/queries.tsv + expected digest
  # device
  hdc file send /tmp/queries.tsv /data/local/tmp/queries.tsv
  hdc shell 'denial_check --index /data/local/tmp/ohos-rk3568.pli \
             --query /data/local/tmp/queries.tsv | sha256sum'
